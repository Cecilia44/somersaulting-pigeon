# somersaulting-pigeon

Analysis scripts associated with the study of the evolutionary and
genetic basis of somersaulting behavior in domestic pigeons.

## Repository structure

- `01_genome_assembly`: Genome assembly and annotation
- `02_population_genomics`: Population structure and selection analyses
- `03_bulk_RNAseq`: Bulk RNA-seq and WGCNA analyses
- `04_single_nucleus_RNAseq`: snRNA-seq analyses
- `05_MRI`: MRI analyses
